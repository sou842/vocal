Start the Colab worker

Needed each time you use Colab GPU.

  1. Open Google Colab → File → Upload notebook → choose colab/vocal_worker.ipynb from this app's folder.
  2. Runtime → Change runtime type → T4 GPU.
  3. Runtime → Run all. The first run installs packages (a few minutes).
  4. When it prints READY, copy the Address and Key here, then Test connection and Save.
  5. Keep the Colab tab open while generating.
